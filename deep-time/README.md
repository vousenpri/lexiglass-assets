# Get a Grip on the Geologic Time Scale

Static site. Deploy on Render as a Static Site with publish directory `deep-time`.
Framed into lexiglass.com via a Code block iframe.

- `index.html` — the whole page (built from game-shell.html + data2.js)
- `img/` — animal, map and why images
- `aud/` — narration clips and full audiobook (ElevenLabs, Lexiglass Pri IVC)
