# The Magpie's Hoard: 25 object pictures

Paste the style line first, then one object line. Save each picture under the file name shown; the page loads img/<name>.jpg, so these replace the light word pictures one for one.

Style line (use with every prompt):
Square picture, 1:1. Painterly realism, like a small oil painting with visible brushwork. Near black background. One object lying in a dark magpie's nest of woven twigs, seen close up and a little from above. The only light is the light described. No text, no people, no hands.
